# milib
Libreria con funciones hechas por Feli

---

## Cómo me puedo instalar la libreria:
Utilizando el comando en la terimal para instalar la libreria modificable que se encuentra en github:
```cmd
pip install git+https://github.com/Blizard32/milib.git
```

Se instalará las dependencias **build**, luego se obtendrán los requerimientos para el **build wheel** que necesita la librería y luego s einstalará la metadata de la librería. Luego de eso se pueden usar, explorar y modificar las funciones dentro de la librería.
<p>

Si se modificaron las funciones (en la librería local o global), se puede reinstalar la librería con el siguiente comando:

```cmd 
pip install --upgrade --force-reinstall git+https://github.com/Blizard32/milib.git
```
